# TopHop Smart Bar — Public Showcase

TopHop Smart Bar is a QR-first digital menu for a modern beer bar. Guests open a table-specific menu, browse a dynamic tap list, inspect product details, build a cart and request a recommendation at product level. Staff get a focused view for menu management and availability changes.

The showcase demonstrates QR table entry, categories, product cards, cart and order review UX, staff availability controls, and neutral recommendation interfaces. Data is synthetic and checkout is local demo behavior; no external service or live integration is called.

## Run locally

```bash
cd tophop-smart-bar-showcase
python3 -m http.server 4173
```

Open http://localhost:4173.

## Current MVP status

This is a product and UI showcase with deterministic demo data and neutral gateway boundaries. Production integrations, persistent storage, credentials, infrastructure and proprietary backend implementation are intentionally excluded.
